# Yêu cầu chức năng

> Mã FR-01…FR-nn, mỗi hàng một tính năng, kèm module sở hữu + docs tham chiếu. Bảng này là **mục lục**; chi tiết nghiệp vụ ở docs §3, luồng ở [`04-luong-nghiep-vu.md`](04-luong-nghiep-vu.md).
> Module: `FE` = Frontend (công khai), `ADM` = Admin (CMS + API `/api/admin/*`), `Core` = dịch vụ dùng chung.
> Trạng thái triển khai ghi theo repo — **rà toàn bảng 13/09/2026 bằng đối chiếu code thật** (không tin docs một mình): **✅** = đã cài đủ nghiệp vụ mô tả (kèm mốc); **🟡** = cài một phần — phần còn thiếu ghi ngay trong ô; **Khung** = class/controller/folder đã tạo nhưng logic chưa cài; **❌** = chưa có code cho tính năng; **Docs** = mới chốt trong tài liệu.
