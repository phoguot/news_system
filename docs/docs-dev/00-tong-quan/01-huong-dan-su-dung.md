# Hướng dẫn sử dụng tài liệu

## Thứ tự đọc gợi ý

```
1. docs/docs-dev/README.md
2. 00-tong-quan/02-tong-quan-du-an.md
3. 00-tong-quan/03-kien-truc-tong-quan.md
4. 00-tong-quan/05-cau-truc-thu-muc.md
5. 01-quy-chuan/00-readme.md
6. 02-thiet-ke/ (tính năng liên quan tới task)
```

## Khi nào tra file nào?

| Tình huống | Mở file |
|------------|---------|
| Không hiểu dự án làm gì | `02-tong-quan-du-an.md` |
| Không hiểu luồng chạy | `03-kien-truc-tong-quan.md` |
| Không biết code ở đâu | `05-cau-truc-thu-muc.md` |
| Chuẩn bị viết code | `01-quy-chuan/` |
| Thêm tính năng mới | `_templates/template-tinh-nang.md` |
| Tích hợp API ngoài | `03-tich-hop/` |
| Chuẩn bị deploy | `05-van-hanh/` |

## Quy tắc cho người viết tài liệu

- Mỗi file có phần gợi ý `> Điền ...` — xóa gợi ý sau khi điền xong.
- Giữ mỗi file ngắn gọn, link tới file chi tiết thay vì copy dài.
- Cập nhật `00-readme.md` của thư mục khi thêm file mới.
